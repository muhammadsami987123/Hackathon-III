## PRODUCT OVERVIEW

### What is LearnFlow?

**LearnFlow** is an AI-powered Python tutoring platform that helps students learn programming through:
- **Conversational AI tutors** that explain concepts and debug code
- **Live code execution** in a sandboxed environment
- **Adaptive learning** that tracks progress and detects struggle
- **Teacher dashboards** for monitoring student performance
- **Automated exercise generation** based on student needs

### Core Value Proposition

Students get:
- ✅ Instant feedback on code
- ✅ Personalized explanations
- ✅ Safe sandbox to experiment
- ✅ Progress tracking
- ✅ AI-powered debugging

Teachers get:
- ✅ Class progress visibility
- ✅ Struggle alerts
- ✅ Auto-generated exercises
- ✅ Performance analytics
- ✅ One-click assignment distribution

### Key Differentiator

Unlike traditional tutoring platforms, LearnFlow uses **specialized AI agents** for different tutoring tasks:
- **Triage Agent:** Routes questions to specialists
- **Concepts Agent:** Explains Python topics
- **Code Review Agent:** Analyzes code quality
- **Debug Agent:** Diagnoses errors
- **Exercise Agent:** Generates and grades challenges
- **Progress Agent:** Tracks mastery

## AI AGENT SYSTEM

### Multi-Agent Architecture

#### **1. Triage Agent**

**Role:** Routes student queries to appropriate specialists

**Logic:**
```
Student: "I got this error: NameError: name 'x' is not defined"

Triage Agent analyzes:
- Keywords: "error", "NameError" → Route to Debug Agent
- Type: Error-focused question

Routes to: Debug Agent
```

**Routing Rules:**
- Contains "error" or exception name → **Debug Agent**
- Contains "explain" or "how" → **Concepts Agent**
- Is code submission → **Code Review Agent**
- Is quiz/exercise → **Exercise Agent**
- Asks about progress → **Progress Agent**
- Ambiguous → Ask for clarification

**Tools Available:**
- Message routing via Kafka
- Conversation history lookup
- Student progress context

#### **2. Concepts Agent**

**Role:** Explains Python concepts with examples

**Capabilities:**
- Explains any Python concept (variables, loops, functions, OOP)
- Adapts explanation to student mastery level
- Provides code examples
- Creates visualizations with ASCII art
- Generates practice questions

**Example Interaction:**
```
Student: "What's the difference between a list and a tuple?"
Mastery Level: Beginner

Concepts Agent Response:

Lists and Tuples are both collections, but:

LISTS: Can change ✓
my_list = [1, 2, 3]
my_list[0] = 99  # Works!
Output: [99, 2, 3]

TUPLES: Cannot change ✗
my_tuple = (1, 2, 3)
my_tuple[0] = 99  # Error!

When to use:
- List: Data will change
- Tuple: Data should not change

Try it yourself!
```

**Personalization:**
- Beginner: Simple explanations, many examples
- Intermediate: More details, fewer examples
- Advanced: Focus on edge cases and performance

#### **3. Code Review Agent**

**Role:** Analyzes code quality and correctness

**Checks:**
- **Correctness:** Does code do what it should?
- **Style:** PEP 8 compliance
- **Efficiency:** Is algorithm optimal?
- **Readability:** Are variable names clear?

**Output:**
```
Code Submission:
```python
x=[]
for i in range(10):
 x.append(i*2)
print(x)
```

Review:
✗ Style issues:
  - Missing spaces around `=`
  - Inconsistent indentation
  - Variable name `x` is unclear

→ Better:
```python
doubled_numbers = []
for number in range(10):
    doubled_numbers.append(number * 2)
print(doubled_numbers)
```

Or even better (Pythonic):
```python
doubled_numbers = [n * 2 for n in range(10)]
print(doubled_numbers)
```

Grade: 60% (works, but needs style improvement)
```

#### **4. Debug Agent**

**Role:** Diagnoses and explains errors

**Process:**
1. Parse error message
2. Identify root cause
3. Explain what went wrong
4. Provide hints (not solutions)
5. Link to concepts if needed

**Example:**
```
Error: TypeError: can only concatenate str (not "int") to str

Debug Agent:
"You tried to add text and a number together:

message = "I am " + 25

Python doesn't know how to combine text + number.

Hint: How would you convert 25 to text?
Hint: Look at the type conversion lesson.

Try: message = "I am " + str(25)
```

#### **5. Exercise Agent**

**Role:** Generates and auto-grades coding challenges

**Generation:**
```
Input: "Create beginner exercises on list indexing"

Generated Exercises:
1. Create a list [10, 20, 30, 40]

```

**Auto-Grading:**
- Execute code in sandbox
- Check output against expected
- Award points for correct solutions
- Provide feedback for incorrect

#### **6. Progress Agent**

**Role:** Tracks and reports learning progress

**Tracking:**
- Exercises completed per topic

- Code quality ratings
- Streak (consecutive days)
- Time spent per module

**Reporting:**

## BUSINESS RULES & ALGORITHMS

### Mastery Calculation

**Formula:**
```
Topic Mastery = (E × 0.40) + (Q × 0.30) + (C × 0.20) + (S × 0.10)

Where:
E = Exercise Completion Score (0-100)
Q = Quiz Score (0-100)
C = Code Quality Rating (0-100)
S = Consistency Streak Bonus (0-20)
```

**Example Calculation:**
```
Student: Maya
Topic: For Loops

Exercises: 4/5 complete = 80%
Quiz: 85%
Code Quality: 90%
Streak: 7 days = 14 bonus points

Mastery = (80 × 0.4) + (85 × 0.3) + (90 × 0.2) + (14 × 0.1)
        = 32 + 25.5 + 18 + 1.4
        = 76.9% → Proficient (Green)
```

### Mastery Levels

| Level | Range | Color | Badge | Capabilities |
|-------|-------|-------|-------|---|
| Beginner | 0-40% | 🔴 Red | 👶 | Basic understanding |
| Learning | 41-70% | 🟡 Yellow | 📚 | Applied knowledge |
| Proficient | 71-90% | 🟢 Green | ✅ | Can teach others |
| Mastered | 91-100% | 🔵 Blue | 🏆 | Expert level |

### Struggle Detection

**Triggers** (any one activates alert):

```
1. Error Pattern
   Same error type 3+ times in a row
   Example: NameError appears in last 3 submissions

2. Time Stuck
   Stuck on single exercise >10 minutes
   Example: Same problem for 12 minutes without progress

3. Quiz Failure
   Score <50% on quiz
   Example: 3/10 correct on Module 2 quiz

4. Explicit Help Request
   Student says "I don't understand" 3+ times
   Or "I'm stuck" within 5 minutes

5. Execution Failures
   Code fails to run 5+ times in a row
   Examples: 5 consecutive syntax/runtime errors

6. Low Engagement
   No activity for 3 days
   Or average session <5 minutes
```

**When Triggered:**
- ✅ Teacher receives notification
- ✅ System generates remedial exercises
- ✅ Concepts Agent proactively offers help
- ✅ Student prompted: "Would you like a hint?"

### Exercise Auto-Generation

**Algorithm:**

```
GenerateExercise(topic, difficulty, student_history):
  1. Retrieve curriculum for topic
  2. Check student's struggle points
  3. Generate 3-5 similar problems
  4. Vary parameters (numbers, structures)
  5. Include scaffolding for lower levels
  6. Return exercises with answers

Example for "List Indexing":
  Beginner:
    my_list = [10, 20, 30]
    print(my_list[0])  # What prints?

    my_list = ['a', 'b', 'c']
    print(my_list[-1])  # Negative index?
    
  Advanced:
    nested = [[1, 2], [3, 4]]
    print(nested[0][1])  # Multi-level indexing
```

## CODE EXECUTION SANDBOX

### Security Constraints

| Constraint | Limit | Reason |
|-----------|-------|--------|
| **Timeout** | 5 seconds | Prevent infinite loops |
| **Memory** | 50MB | Resource containment |
| **CPU** | 1 core | Fair resource sharing |
| **Disk** | None (except /tmp) | Prevent file writing |
| **Network** | None | Security isolation |
| **File System** | /tmp only | No permanent storage |
| **Permissions** | Non-root | Can't escalate privileges |

### Allowed Imports (MVP)

```python
# Standard Library Only
import math
import random
import string
import datetime
import json
import csv
import re
import itertools
import collections
# ... other standard library modules

# NOT allowed in MVP
import requests  # No network
import os        # Limited file access
import subprocess # Can't execute commands
import sys       # Limited system access
```

### Sandbox Execution Flow

```
1. User submits code in editor
   ↓
2. Code sent to Code Runner Service
   ↓
3. Service validates (no blocked imports/functions)
   ↓
4. Create isolated Docker container
   - Mount /tmp (read/write)
   - Set memory limit: 50MB
   - Set timeout: 5 seconds
   - Drop capabilities (no sudo)
   ↓
5. Execute code in container
   ↓
6. Capture stdout/stderr
   ↓
7. Kill container (cleanup)
   ↓
8. Return output to user
   ↓
9. Code Review Agent analyzes
   ↓
10. Publish event to Kafka (code.executed)
```

## DATABASE SCHEMA

### Core Tables

#### users
```sql
CREATE TABLE users (
    id UUID PRIMARY KEY,
    email VARCHAR UNIQUE NOT NULL,
    name VARCHAR NOT NULL,
    password_hash VARCHAR NOT NULL,
    role ENUM('student', 'teacher') NOT NULL,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

#### classrooms
```sql
CREATE TABLE classrooms (
    id UUID PRIMARY KEY,
    name VARCHAR NOT NULL,
    teacher_id UUID REFERENCES users(id),
    code VARCHAR UNIQUE NOT NULL,  -- Join code
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

#### class_enrollments
```sql
CREATE TABLE class_enrollments (
    id UUID PRIMARY KEY,
    classroom_id UUID REFERENCES classrooms(id),
    student_id UUID REFERENCES users(id),
    enrolled_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(classroom_id, student_id)
);
```

#### student_progress
```sql
CREATE TABLE student_progress (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES users(id),
    module INT NOT NULL,  -- 1-8
    topic VARCHAR NOT NULL,
    mastery_level DECIMAL(5,2) DEFAULT 0,  -- 0-100
    exercises_completed INT DEFAULT 0,
    quizzes_taken INT DEFAULT 0,
    last_quiz_score DECIMAL(5,2),
    updated_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(student_id, module, topic)
);
```

#### code_submissions
```sql
CREATE TABLE code_submissions (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES users(id),
    exercise_id VARCHAR NOT NULL,
    code_text TEXT NOT NULL,
    output TEXT,
    grade DECIMAL(5,2),
    feedback TEXT,
    submitted_at TIMESTAMP DEFAULT NOW(),
    execution_time DECIMAL(5,3)
);
```

#### quiz_responses
```sql
CREATE TABLE quiz_responses (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES users(id),
    quiz_id VARCHAR NOT NULL,
    score DECIMAL(5,2) NOT NULL,
    answers JSONB NOT NULL,
    completed_at TIMESTAMP DEFAULT NOW()
);
```

#### struggle_alerts
```sql
CREATE TABLE struggle_alerts (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES users(id),
    classroom_id UUID REFERENCES classrooms(id),
    trigger_type VARCHAR NOT NULL,  -- error_pattern, time_stuck, etc
    description TEXT NOT NULL,
    resolved BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT NOW(),
    resolved_at TIMESTAMP
);
```

## PRODUCT OVERVIEW

### What is LearnFlow?

**LearnFlow** is an AI-powered Python tutoring platform that helps students learn programming through:
- **Conversational AI tutors** that explain concepts and debug code
- **Live code execution** in a sandboxed environment
- **Adaptive learning** that tracks progress and detects struggle
- **Teacher dashboards** for monitoring student performance
- **Automated exercise generation** based on student needs

### Core Value Proposition

Students get:
- ✅ Instant feedback on code
- ✅ Personalized explanations
- ✅ Safe sandbox to experiment
- ✅ Progress tracking
- ✅ AI-powered debugging

Teachers get:
- ✅ Class progress visibility
- ✅ Struggle alerts
- ✅ Auto-generated exercises
- ✅ Performance analytics
- ✅ One-click assignment distribution

### Key Differentiator

Unlike traditional tutoring platforms, LearnFlow uses **specialized AI agents** for different tutoring tasks:
- **Triage Agent:** Routes questions to specialists
- **Concepts Agent:** Explains Python topics
- **Code Review Agent:** Analyzes code quality
- **Debug Agent:** Diagnoses errors
- **Exercise Agent:** Generates and grades challenges
- **Progress Agent:** Tracks mastery

## AI AGENT SYSTEM

### Multi-Agent Architecture

#### **1. Triage Agent**

**Role:** Routes student queries to appropriate specialists

**Logic:**
```
Student: "I got this error: NameError: name 'x' is not defined"

Triage Agent analyzes:
- Keywords: "error", "NameError" → Route to Debug Agent
- Type: Error-focused question

Routes to: Debug Agent
```

**Routing Rules:**
- Contains "error" or exception name → **Debug Agent**
- Contains "explain" or "how" → **Concepts Agent**
- Is code submission → **Code Review Agent**
- Is quiz/exercise → **Exercise Agent**
- Asks about progress → **Progress Agent**
- Ambiguous → Ask for clarification

**Tools Available:**
- Message routing via Kafka
- Conversation history lookup
- Student progress context

#### **2. Concepts Agent**

**Role:** Explains Python concepts with examples

**Capabilities:**
- Explains any Python concept (variables, loops, functions, OOP)
- Adapts explanation to student mastery level
- Provides code examples
- Creates visualizations with ASCII art
- Generates practice questions

**Example Interaction:**
```
Student: "What's the difference between a list and a tuple?"
Mastery Level: Beginner

Concepts Agent Response:

Lists and Tuples are both collections, but:

LISTS: Can change ✓
my_list = [1, 2, 3]
my_list[0] = 99  # Works!
Output: [99, 2, 3]

TUPLES: Cannot change ✗
my_tuple = (1, 2, 3)
my_tuple[0] = 99  # Error!

When to use:
- List: Data will change
- Tuple: Data should not change

Try it yourself!
```

**Personalization:**
- Beginner: Simple explanations, many examples
- Intermediate: More details, fewer examples
- Advanced: Focus on edge cases and performance

#### **3. Code Review Agent**

**Role:** Analyzes code quality and correctness

**Checks:**
- **Correctness:** Does code do what it should?
- **Style:** PEP 8 compliance
- **Efficiency:** Is algorithm optimal?
- **Readability:** Are variable names clear?

**Output:**
```
Code Submission:
```python
x=[]

## BUSINESS RULES & ALGORITHMS

### Mastery Calculation

**Formula:**
```
Topic Mastery = (E × 0.40) + (Q × 0.30) + (C × 0.20) + (S × 0.10)

Where:
E = Exercise Completion Score (0-100)
Q = Quiz Score (0-100)
C = Code Quality Rating (0-100)
S = Consistency Streak Bonus (0-20)
```

**Example Calculation:**
```
Student: Maya
Topic: For Loops

Exercises: 4/5 complete = 80%
Quiz: 85%
Code Quality: 90%
Streak: 7 days = 14 bonus points

Mastery = (80 × 0.4) + (85 × 0.3) + (90 × 0.2) + (14 × 0.1)
        = 32 + 25.5 + 18 + 1.4
        = 76.9% → Proficient (Green)
```

|-------|-------|-------|-------|---|
| Beginner | 0-40% | 🔴 Red | 👶 | Basic understanding |

### Struggle Detection

**Triggers** (any one activates alert):

```
1. Error Pattern
   Same error type 3+ times in a row
   Example: NameError appears in last 3 submissions

2. Time Stuck
   Stuck on single exercise >10 minutes
   Example: Same problem for 12 minutes without progress

3. Quiz Failure
   Score <50% on quiz
   Example: 3/10 correct on Module 2 quiz

4. Explicit Help Request
   Student says "I don't understand" 3+ times
   Or "I'm stuck" within 5 minutes

5. Execution Failures
   Code fails to run 5+ times in a row
   Examples: 5 consecutive syntax/runtime errors

6. Low Engagement
   No activity for 3 days
   Or average session <5 minutes
```

**When Triggered:**
- ✅ Teacher receives notification
- ✅ System generates remedial exercises
- ✅ Concepts Agent proactively offers help
- ✅ Student prompted: "Would you like a hint?"

## CODE EXECUTION SANDBOX

### Security Constraints

| Constraint | Limit | Reason |
|-----------|-------|--------|
| **Timeout** | 5 seconds | Prevent infinite loops |
| **Memory** | 50MB | Resource containment |
| **CPU** | 1 core | Fair resource sharing |
| **Disk** | None (except /tmp) | Prevent file writing |
| **Network** | None | Security isolation |
| **File System** | /tmp only | No permanent storage |
| **Permissions** | Non-root | Can't escalate privileges |

### Allowed Imports (MVP)

```python
# Standard Library Only
import math
import random
import string
import datetime
import json
import csv
import re
import itertools
import collections
# ... other standard library modules

# NOT allowed in MVP
import requests  # No network
import os        # Limited file access
import subprocess # Can't execute commands
import sys       # Limited system access
```

### Sandbox Execution Flow

```
1. User submits code in editor
   ↓
2. Code sent to Code Runner Service
   ↓
3. Service validates (no blocked imports/functions)
   ↓
4. Create isolated Docker container
   - Mount /tmp (read/write)
   - Set memory limit: 50MB
   - Set timeout: 5 seconds
   - Drop capabilities (no sudo)
   ↓
5. Execute code in container
   ↓
6. Capture stdout/stderr
   ↓
7. Kill container (cleanup)
   ↓
8. Return output to user
   ↓
9. Code Review Agent analyzes
   ↓
10. Publish event to Kafka (code.executed)
```
