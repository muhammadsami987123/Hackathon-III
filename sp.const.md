## CORE MISSION

Transform the Spec-Kit Plus framework into an **agent-agnostic** platform by:

1. **Unifying** playbook standards (CAPS format)
2. **Formalizing** compilation from CAPS → Claude Skills + Goose Recipes
3. **Bi-directional testing** to prove portability
4. **Building** LearnFlow application autonomously via AI agents

**Paradigm Shift:**
- **Before:** Write code → Code runs → App works
- **After:** Write playbooks → AI learns → AI writes code → App works

## CRITICAL SUCCESS FACTORS

### 1. **CAPS Specification Must Be Crystal Clear**
- Every field maps cleanly to both Claude Skills and Goose Recipes
- No ambiguity in tool definitions or execution steps
- Version control for future CAPS iterations

### 2. **Sync Scripts Must Be Bulletproof**
- Validate YAML syntax after generation
- Test with actual Claude Code and Goose agents
- Include error messages and debugging output

### 3. **Playbooks Must Be AI-Friendly**
- Step-by-step, unambiguous instructions
- Include validation/success criteria
- Handle common error scenarios
- Reference exact tool names and parameters

### 4. **Bi-Directional Portability**
- Same business logic, different agent execution
- Both versions achieve feature parity
- Document any agent-specific workarounds

### 5. **Documentation Automates Onboarding**
- AGENTS.md in every repo explains structure to AI
- Docusaurus site generated from CAPS playbooks
- Examples show Claude Code vs Goose patterns
