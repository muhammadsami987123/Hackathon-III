## MACOS INSTALLATION

### Step 1: Install Homebrew

```bash
# Check if Homebrew is installed
brew --version

# If not installed, install Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Verify installation
brew --version
```

Expected output:
```
Homebrew 4.0.0
```

### Step 2: Install Docker

```bash
# Install Docker Desktop via Homebrew
brew install --cask docker

# Start Docker Desktop (or open from Applications)
open -a Docker

# Wait 30 seconds for Docker to start, then verify
docker --version
```

Expected output:
```
Docker version 20.10.0+
```

If Docker fails to start:
1. Go to Applications → Docker
2. Authorize with your macOS password
3. Wait for Docker icon to appear in menu bar

### Step 3: Install Minikube

```bash
# Install Minikube
brew install minikube

# Verify installation
minikube version
```

Expected output:
```
minikube version: v1.30.0+
```

### Step 4: Start Minikube

```bash
# Start Minikube with recommended resources
minikube start --cpus=4 --memory=8192 --driver=docker

# This will take 2-3 minutes the first time
# Expected output: "Done!"
```

### Step 5: Install Helm

```bash
# Install Helm
brew install helm

# Verify installation
helm version
```

Expected output:
```
version.BuildInfo{Version:"v3.12.0", ...}
```

### Step 6: Install kubectl

kubectl is installed automatically with Minikube, but verify:

```bash
# Verify kubectl
kubectl version --client --short
```

Expected output:
```
Client Version: v1.27.0
```

### Step 7: Install Claude Code


## VERIFICATION

### Complete Verification Script

Create a file called `verify-environment.sh`:

```bash
#!/bin/bash
# verify-environment.sh
# Complete environment verification

echo "=========================================="
echo "Hackathon 3 Environment Verification"
echo "=========================================="
echo ""

# Color output
GREEN='\033[0;32m'
RED='\033[0;31m'
NC='\033[0m'

check_command() {
    if command -v $1 &> /dev/null; then
        echo -e "${GREEN}✓${NC} $1 is installed"
        return 0
    else
        echo -e "${RED}✗${NC} $1 is NOT installed"
        return 1
    fi
}

echo "Checking core tools..."
check_command git
check_command docker
check_command minikube
check_command kubectl
check_command helm
check_command claude
check_command goose

echo ""
echo "Checking Kubernetes cluster..."
if minikube status > /dev/null 2>&1; then
    echo -e "${GREEN}✓${NC} Minikube is running"
else
    echo -e "${RED}✗${NC} Minikube is NOT running"
    echo "  Start with: minikube start --cpus=4 --memory=8192 --driver=docker"
fi

echo ""
echo "Checking cluster connectivity..."
if kubectl cluster-info > /dev/null 2>&1; then
    echo -e "${GREEN}✓${NC} kubectl can connect to cluster"
else
    echo -e "${RED}✗${NC} kubectl cannot connect"
fi

echo ""
echo "Checking repositories..."
if [ -d ~/projects/skills-library ]; then
    echo -e "${GREEN}✓${NC} skills-library repository exists"
else
    echo -e "${RED}✗${NC} skills-library repository NOT found"
fi

if [ -d ~/projects/learnflow-app ]; then
    echo -e "${GREEN}✓${NC} learnflow-app repository exists"
else
    echo -e "${RED}✗${NC} learnflow-app repository NOT found"
fi

echo ""
echo "=========================================="
echo "Verification Complete!"
echo "=========================================="
```

Run the verification:

```bash
# Make script executable
chmod +x verify-environment.sh

# Run verification
./verify-environment.sh
```

Expected output:
```
✓ git is installed
✓ docker is installed
✓ minikube is installed
✓ kubectl is installed
✓ helm is installed
✓ claude is installed
✓ goose is installed
✓ Minikube is running
✓ kubectl can connect to cluster
✓ skills-library repository exists
✓ learnflow-app repository exists

Verification Complete!
```

## TROUBLESHOOTING

### Docker Issues

**Problem:** Docker won't start
```bash
# macOS
open -a Docker

# Linux: Check if Docker daemon is running
sudo systemctl status docker
sudo systemctl start docker

# Windows (WSL): Restart Docker Desktop
```

**Problem:** "Cannot connect to Docker daemon"
```bash
# macOS: Open Docker Desktop from Applications
# Linux: Add user to docker group
sudo usermod -aG docker $USER
newgrp docker

# Windows: Enable WSL 2 integration in Docker Desktop
```

### Minikube Issues

**Problem:** "Exiting due to DRV_NOT_HEALTHY"
```bash
# Delete and restart
minikube delete
minikube start --cpus=4 --memory=8192 --driver=docker

# For Mac M1/M2
minikube start --driver=docker --alsologtostderr
```

**Problem:** "Insufficient disk space"
```bash
# Check disk usage
minikube ssh "df -h"

# Free up space
docker system prune -a

# Recreate cluster
minikube delete
minikube start --cpus=4 --memory=8192 --disk-size=50000mb
```

### kubectl Issues

**Problem:** "The connection to the server was refused"
```bash
# Check Minikube status
minikube status

# Restart Minikube
minikube stop
minikube start

# Configure kubectl
minikube update-context
```

### Claude Code Issues

**Problem:** Claude Code not found
```bash
# macOS: Reinstall
brew uninstall claude-code
brew install --cask claude-code

# Linux: Reinstall
curl -fsSL https://claude.ai/install.sh | bash

# Verify path
which claude
```

**Problem:** Authentication fails
```bash
# Re-authenticate
claude auth logout
claude auth login
```

### Goose Issues

**Problem:** Goose not recognized
```bash
# Verify installation
which goose

# Add to PATH if needed
export PATH="$PATH:$HOME/.goose/bin"

# Reinstall if needed
curl -fsSL https://github.com/block/goose/releases/download/stable/download_cli.sh | bash
```

## ENVIRONMENT VARIABLES

Add these to your shell profile (`~/.bashrc`, `~/.zshrc`, or `~/.profile`):

```bash
# Kubernetes
export KUBECONFIG=~/.kube/config

# Helm
export HELM_HOME=~/.helm

# Docker
export DOCKER_HOST="unix://$HOME/.docker/run/docker.sock"

# Claude Code
export CLAUDE_HOME=~/.claude

# Minikube
export MINIKUBE_HOME=~/.minikube
```

### Apply Changes

```bash
# Bash
source ~/.bashrc

# Zsh
source ~/.zshrc
```
