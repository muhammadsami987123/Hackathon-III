## OVERVIEW

The **MCP Code Execution Pattern** is Hackathon 3's core innovation. Instead of loading massive MCP tool definitions into the agent's context, you wrap them in minimal Skills that execute external scripts.

### The Paradigm Shift

#### **Old Approach (Hackathon 2): Direct MCP**
```
Agent Context: [MCP tools loaded] → [Tool results] → [Processing]
Token Cost: 50,000+ before you start
```

#### **New Approach (Hackathon 3): Skills + Scripts**
```
Agent Context: [Skill.md ~100 tokens] → [Script executes] → [Result returned]
Token Cost: 110 tokens total (80-98% reduction)
```

### Why This Matters

| Scenario | Direct MCP | Skills + Scripts | Savings |
|----------|-----------|------------------|---------|
| Single deployment | 50,000 tokens | 110 tokens | 99.8% |
| 10 tool calls | 50,000 + 50,000 | 110 + 20 | 99.9% |
| Complex workflow | 50,000 + 100,000 | 110 + 100 | 99.9% |

**Real-world impact:** Same capability, 400-800x fewer tokens = longer conversations, faster responses, lower cost.

## THE TOKEN PROBLEM

### How MCP Tools Consume Context

When you connect MCP servers directly:

#### **Problem 1: Tool Definition Loading**

```json
{
  "servers": {
    "kubernetes": {
      "command": "mcp-k8s-server",
      "tools": [
        {
          "name": "kubectl_get_pods",
          "description": "List all pods in namespace...",
          "inputSchema": {
            "type": "object",
            "properties": { ... 50+ properties }
          }
        },
        // ... 24 more tools like this
      ]
    }
  }
}
```

**Result:** ~15,000 tokens loaded at startup, every session

#### **Problem 2: Data Bloat in Context**

When the agent calls a tool, the full result flows through context:

```bash
TOOL CALL: kubectl_get_pods(namespace: "kafka")

RESULT: [
  {
    "metadata": { "name": "kafka-0", "uid": "...", ... },
    "status": { 
      "phase": "Running",
      "conditions": [ ... ],
      "podIP": "...",
      "containerStatuses": [ ... ]
    }
  },
  // ... repeat for 100+ pods
]
```

**Result:** Each call adds 25,000+ tokens to context

#### **Problem 3: Transcript Duplication**

When passing results to another tool:

```
TOOL CALL 1: kubectl_get_pods(namespace: "kafka")
  → Returns 25,000 tokens to context

TOOL CALL 2: apply_manifest(data: { pods: [full result from step 1] })
  → Same 25,000 tokens written again to context

Total: 50,000 tokens for a simple operation
```

### Total Cost Example

```
Session Setup:
- MCP tool definitions: 15,000 tokens
- Kubernetes server: 15,000 tokens  
- PostgreSQL server: 15,000 tokens
Total before first prompt: 45,000 tokens

First workflow:
- Get pods: 25,000 tokens
- Get logs: 20,000 tokens
- Apply config: 15,000 tokens (includes duplication)
Total: 60,000 tokens

Total consumed: 105,000 tokens (35% of 300k context window!)
```

## THE SOLUTION ARCHITECTURE

### Core Insight

**Move processing from Agent Context to Script Execution**

```
Before (MCP loads 50,000 tokens):
┌─────────────────────────────────────────┐
│ Agent Context Window (300k tokens)      │
├─────────────────────────────────────────┤
│ MCP Tool Definitions (15k tokens)       │
│ Previous Results (25k tokens)           │
│ Conversation (rest)                     │
├─────────────────────────────────────────┤
│ 45,000 tokens consumed before task      │
└─────────────────────────────────────────┘

After (Skill loads 100 tokens):
┌─────────────────────────────────────────┐
│ Agent Context Window (300k tokens)      │
├─────────────────────────────────────────┤
│ SKILL.md (~100 tokens)                  │
│ Script output (~10 tokens)              │
│ Conversation (rest)                     │
├─────────────────────────────────────────┤
│ 110 tokens consumed, 297k available     │
└─────────────────────────────────────────┘
```

### The Pattern: 4-Part Structure

```
.claude/skills/{skill-name}/
├── SKILL.md           # What agent loads (~100 tokens)
├── REFERENCE.md       # Deep docs (loaded on-demand only)
├── scripts/
│   ├── main.sh        # Entry point
│   ├── deploy.py      # Does actual work
│   └── verify.py      # Checks success
└── examples/
    └── config.yaml    # Optional: Usage examples
```

Minimal instructions for the agent:

```markdown
- Check: kubectl describe pod
```

**Agent sees:** Only if explicitly asks "show reference" (~1k tokens)

```yaml
  size: 100Gi
```

**Agent sees:** Only if references them

## WRITING EFFICIENT SCRIPTS

### Script Philosophy

**Rule 1:** Do all work in scripts, not context  
**Rule 2:** Return only final status to agent  
**Rule 3:** Handle errors gracefully  
**Rule 4:** Exit with meaningful codes  

### Python Script Pattern

```python
#!/usr/bin/env python3
"""
Script: Deploy Kafka to Kubernetes
Returns: Minimal status, errors handled internally
"""

import subprocess
import sys
import json
from typing import Dict, List

class KafkaDeployer:
    """Handles Kafka deployment with error handling"""
    
    def __init__(self, namespace: str = "kafka"):
        self.namespace = namespace
        self.errors = []
    
    def run_command(self, cmd: List[str]) -> bool:
        """Execute command, capture output, handle errors"""
        try:
            result = subprocess.run(
                cmd,
                capture_output=True,
                text=True,
                timeout=300,
                check=True
            )
            return True
        except subprocess.CalledProcessError as e:
            self.errors.append(f"Command failed: {' '.join(cmd)}")
            self.errors.append(f"Error: {e.stderr}")
            return False
        except TimeoutError:
            self.errors.append(f"Command timed out: {' '.join(cmd)}")
            return False
    
    def deploy(self) -> bool:
        """Deploy Kafka - all work happens here"""
        
        # Add Helm repo
        if not self.run_command([
            "helm", "repo", "add", "bitnami",
            "https://charts.bitnami.com/bitnami"
        ]):
            return False
        
        if not self.run_command(["helm", "repo", "update"]):
            return False
        
        # Create namespace
        if not self.run_command([
            "kubectl", "create", "namespace", self.namespace,
            "--dry-run=client", "-o", "yaml", "|", "kubectl", "apply", "-f", "-"
        ]):
            return False
        
        # Install Kafka
        if not self.run_command([
            "helm", "install", "kafka", "bitnami/kafka",
            "--namespace", self.namespace,
            "--set", "replicaCount=1",
            "--set", "zookeeper.replicaCount=1",
            "--wait", "--timeout", "5m"
        ]):
            return False
        
        return True
    
    def get_status(self) -> Dict:
        """Return only minimal status to agent"""
        if self.errors:
            return {
                "status": "failed",
                "errors": self.errors[:3],  # First 3 errors only
                "message": f"Deployment failed: {self.errors[0]}"
            }
        else:
            return {
                "status": "success",
                "message": "✓ Kafka deployed to namespace 'kafka'"
            }

def main():
    deployer = KafkaDeployer(namespace="kafka")
    success = deployer.deploy()
    
    status = deployer.get_status()
    
    # Print only what agent needs to see
    print(status["message"])
    
    # All work is done, only minimal output goes to context
    sys.exit(0 if success else 1)

if __name__ == "__main__":
    main()
```

**What agent sees in context:**
```
✓ Kafka deployed to namespace 'kafka'
```

**What happens behind scenes:** Helm repos, kubectl calls, error handling, retries - all invisible to token counter.

### Bash Script Pattern

```bash
#!/bin/bash
# scripts/main.sh - Entry point
# Philosophy: Orchestrate work, return minimal status

set -euo pipefail

NAMESPACE="${1:-kafka}"
LOG_FILE="/tmp/kafka-deploy-$(date +%s).log"

# All work logged to file, not context
{
    echo "Starting Kafka deployment..."
    
    # Deploy
    ./scripts/deploy.py --namespace "$NAMESPACE" || {
        echo "Deployment failed"
        exit 1
    }
    
    # Verify
    ./scripts/verify.py --namespace "$NAMESPACE" || {
        echo "Verification failed"
        exit 1
    }
    
    echo "Deployment complete"
} >> "$LOG_FILE" 2>&1

# Only final status to agent
if [ $? -eq 0 ]; then
    echo "✓ Kafka deployed successfully"
    echo "  Namespace: $NAMESPACE"
    echo "  Check logs: $LOG_FILE"
    exit 0
else
    echo "✗ Deployment failed - check logs: $LOG_FILE"
    tail -20 "$LOG_FILE"
    exit 1
fi
```

### Verification Script Pattern

```python
#!/usr/bin/env python3
"""
Script: Verify Kafka deployment
Returns: Simple status, no raw pod data
"""

import subprocess
import json
import sys

def check_pods(namespace: str) -> bool:
    """Check if all pods running"""
    result = subprocess.run(
        ["kubectl", "get", "pods", "-n", namespace, "-o", "json"],
        capture_output=True,
        text=True
    )
    
    if result.returncode != 0:
        print(f"✗ Cannot access namespace {namespace}")
        return False
    
    pods = json.loads(result.stdout)["items"]
    
    if not pods:
        print(f"✗ No pods found in {namespace}")
        return False
    
    running = sum(1 for p in pods if p["status"]["phase"] == "Running")
    total = len(pods)
    
    # Return only summary, not full pod list
    if running == total:
        print(f"✓ All {total} pods running")
        return True
    else:
        print(f"⚠ {running}/{total} pods running")
        return False

def check_services(namespace: str) -> bool:
    """Check if services created"""
    result = subprocess.run(
        ["kubectl", "get", "svc", "-n", namespace],
        capture_output=True,
        text=True
    )
    
    if "kafka" in result.stdout:
        print("✓ Kafka service exists")
        return True
    else:
        print("✗ Kafka service not found")
        return False

def main():
    namespace = "kafka"
    
    all_ok = True
    all_ok = check_pods(namespace) and all_ok
    all_ok = check_services(namespace) and all_ok
    
    # Simple exit code
    sys.exit(0 if all_ok else 1)

if __name__ == "__main__":
    main()
```

**What agent sees:**
```
✓ All 3 pods running
✓ Kafka service exists
```

**What doesn't appear in context:** Full pod descriptions, service specs, status conditions - all filtered out by script.

## Troubleshooting

### Problem: Pods stuck in Pending

**Check:**
```bash
kubectl describe pod kafka-0 -n kafka
kubectl get events -n kafka
```

**Solution:**
- Insufficient cluster memory: `minikube start --memory=8192`
- No storage class: Create local storage provisioner
- Missing namespace: Manually create with `kubectl create namespace kafka`

### Problem: Service not accessible

**Check:**
```bash
kubectl get svc -n kafka
kubectl get endpoints -n kafka
```

**Solution:**
- Port-forward: `kubectl port-forward svc/kafka 9092:9092 -n kafka`
- Check pod logs: `kubectl logs kafka-0 -n kafka`

### Problem: Topics not created

**Check:**
```bash
kubectl exec kafka-0 -n kafka -- \
  kafka-topics.sh --list --bootstrap-server localhost:9092
```

**Solution:**
- Manually create topics (see Topic Management section)
- Verify Kafka is fully started (wait 30 seconds)

```python
#!/usr/bin/env python3
"""
Kafka Deployment Script
Deploys Kafka to Kubernetes via Helm
All work happens here - minimal output to agent
"""

import subprocess
import sys
import argparse
from typing import List, Tuple

class HelmDeployer:
    def __init__(self, namespace: str):
        self.namespace = namespace
        self.errors = []
    
    def run(self, cmd: List[str], description: str = "") -> Tuple[bool, str]:
        """Execute command, return success/error"""
        try:
            result = subprocess.run(
                cmd,
                capture_output=True,
                text=True,
                timeout=600,
                check=True
            )
            return True, result.stdout
        except subprocess.CalledProcessError as e:
            error_msg = f"{description}: {e.stderr}"
            self.errors.append(error_msg)
            return False, error_msg
        except Exception as e:
            error_msg = f"{description}: {str(e)}"
            self.errors.append(error_msg)
            return False, error_msg
    
    def add_helm_repo(self) -> bool:
        """Add Bitnami Helm repository"""
        success, _ = self.run(
            ["helm", "repo", "add", "bitnami", "https://charts.bitnami.com/bitnami"],
            "Add Helm repo"
        )
        if not success:
            return False
        
        success, _ = self.run(["helm", "repo", "update"], "Update Helm repos")
        return success
    
    def create_namespace(self) -> bool:
        """Create namespace if it doesn't exist"""
        cmd = [
            "kubectl", "create", "namespace", self.namespace,
            "--dry-run=client", "-o", "yaml"
        ]
        success, yaml_output = self.run(cmd, "Generate namespace YAML")
        if not success:
            return False
        
        # Apply the YAML
        apply_cmd = ["kubectl", "apply", "-f", "-"]
        try:
            subprocess.run(
                apply_cmd,
                input=yaml_output,
                text=True,
                check=True,
                capture_output=True
            )
            return True
        except subprocess.CalledProcessError as e:
            self.errors.append(f"Create namespace: {e.stderr}")
            return False
    
    def install_kafka(self) -> bool:
        """Install Kafka via Helm"""
        cmd = [
            "helm", "install", "kafka", "bitnami/kafka",
            "--namespace", self.namespace,
            "--set", "replicaCount=1",
            "--set", "zookeeper.replicaCount=1",
            "--set", "resources.requests.memory=2Gi",
            "--wait",
            "--timeout", "5m"
        ]
        success, _ = self.run(cmd, "Install Kafka")
        return success
    
    def create_topics(self) -> bool:
        """Create default topics"""
        topics = ["learning.explained", "code.executed", "exercise.failed"]
        
        for topic in topics:
            cmd = [
                "kubectl", "exec", "-it", "kafka-0", "-n", self.namespace, "--",
                "kafka-topics.sh",
                "--create",
                "--topic", topic,
                "--bootstrap-server", "localhost:9092",
                "--partitions", "3",
                "--replication-factor", "1",
                "--if-not-exists"
            ]
            success, _ = self.run(cmd, f"Create topic {topic}")
            if not success:
                return False
        
        return True
    
    def deploy(self) -> bool:
        """Execute full deployment"""
        print("Step 1: Adding Helm repository...")
        if not self.add_helm_repo():
            return False
        
        print("Step 2: Creating namespace...")
        if not self.create_namespace():
            return False
        
        print("Step 3: Installing Kafka cluster...")
        if not self.install_kafka():
            return False
        
        print("Step 4: Creating default topics...")
        if not self.create_topics():
            return False
        
        print("Deployment complete!")
        return True

def main():
    parser = argparse.ArgumentParser(description="Deploy Kafka to Kubernetes")
    parser.add_argument("--namespace", default="kafka", help="Kubernetes namespace")
    args = parser.parse_args()
    
    deployer = HelmDeployer(namespace=args.namespace)
    success = deployer.deploy()
    
    if not success:
        print(f"Error: {deployer.errors[0] if deployer.errors else 'Unknown error'}")
        sys.exit(1)
    
    sys.exit(0)

if __name__ == "__main__":
```

```python
#!/usr/bin/env python3
"""
Kafka Verification Script
Checks deployment health
Returns only status summary, not raw data
"""

import subprocess
import json
import sys
import argparse

class KafkaVerifier:
    def __init__(self, namespace: str):
        self.namespace = namespace
        self.checks_passed = []
        self.checks_failed = []
    
    def run_command(self, cmd):
        """Execute kubectl command"""
        result = subprocess.run(cmd, capture_output=True, text=True)
        return result.returncode == 0, result.stdout, result.stderr
    
    def check_pods(self) -> bool:
        """Verify all pods running"""
        success, stdout, _ = self.run_command([
            "kubectl", "get", "pods", "-n", self.namespace, "-o", "json"
        ])
        
        if not success:
            self.checks_failed.append("Cannot access pods")
            return False
        
        try:
            pods = json.loads(stdout)["items"]
            if not pods:
                self.checks_failed.append("No pods found")
                return False
            
            running = sum(1 for p in pods if p["status"]["phase"] == "Running")
            total = len(pods)
            
            # Return only summary
            if running == total:
                self.checks_passed.append(f"✓ All {total} pods running")
                return True
            else:
                self.checks_failed.append(f"Only {running}/{total} pods running")
                return False
        except json.JSONDecodeError:
            self.checks_failed.append("Cannot parse pod data")
            return False
    
    def check_services(self) -> bool:
        """Verify Kafka service exists"""
        success, stdout, _ = self.run_command([
            "kubectl", "get", "svc", "-n", self.namespace
        ])
        
        if "kafka" in stdout:
            self.checks_passed.append("✓ Kafka service exists")
            return True
        else:
            self.checks_failed.append("Kafka service not found")
            return False
    
    def check_topics(self) -> bool:
        """Verify default topics created"""
        cmd = [
            "kubectl", "exec", "-it", "kafka-0", "-n", self.namespace, "--",
            "kafka-topics.sh", "--list", "--bootstrap-server", "localhost:9092"
        ]
        success, stdout, _ = self.run_command(cmd)
        
        if success and "learning" in stdout:
            self.checks_passed.append("✓ Default topics created")
            return True
        else:
            self.checks_failed.append("Topics not accessible")
            return False
    
    def verify(self) -> bool:
        """Run all verification checks"""
        self.check_pods()
        self.check_services()
        self.check_topics()
        
        # Print only summary
        for check in self.checks_passed:
            print(check)
        
        for check in self.checks_failed:
            print(f"⚠ {check}")
        
        return len(self.checks_failed) == 0

def main():
    parser = argparse.ArgumentParser(description="Verify Kafka deployment")
    parser.add_argument("--namespace", default="kafka")
    args = parser.parse_args()
    
    verifier = KafkaVerifier(namespace=args.namespace)
    success = verifier.verify()
    
    sys.exit(0 if success else 1)

if __name__ == "__main__":
    main()
```

The REFERENCE.md file contains deep documentation loaded on-demand only.

### Structure

```markdown
# {Skill Name} - Reference Documentation

## Overview
[Architecture, how it works, design decisions]

```

### Key Principle

REFERENCE.md is **NOT loaded by default**. Agent only sees it if:
- Agent explicitly asks: "Show me the reference"
- Agent needs help with "advanced configuration"
- Agent searches documentation

**Token cost:** 0 until requested

## BEST PRACTICES

### ✅ DO

1. **Keep SKILL.md Minimal**
   - Under 100 lines
   - 4-5 key sections
   - Link to REFERENCE.md for details

2. **Move All Work to Scripts**
   - Python for complex logic
   - Bash for orchestration
   - Handle errors in script

3. **Return Minimal Output**
   - Status messages only
   - Success/failure indicators
   - Maybe 1-2 actionable items

4. **Test Both Agents**
   - Claude Code: `claude --skill name`
   - Goose: `goose --skill name`
   - Verify identical behavior

5. **Use Exit Codes Properly**
   - Exit 0 = success
   - Exit 1 = failure
   - Exit 2 = warning (recoverable)

6. **Handle Errors Gracefully**
   - Try/except in Python
   - set -euo pipefail in Bash
   - Meaningful error messages

### ❌ DON'T

1. **Load Large Data into Context**
   - Don't return raw kubectl output
   - Don't echo full logs
   - Don't show intermediate results

2. **Make MCP Calls Directly**
   - Wrap in scripts instead
   - Let script handle API calls
   - Return filtered results

3. **Hard-code Values**
   - Use parameters/arguments
   - Support environment variables
   - Make scripts flexible

4. **Skip Error Handling**
   - Always validate commands succeeded
   - Handle timeout scenarios
   - Provide debugging info in logs

5. **Forget REFERENCE.md**
   - Users will need configuration
   - Document advanced options
   - Include troubleshooting
