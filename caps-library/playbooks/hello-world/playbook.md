# Hello World CAPS Playbook

A simple CAPS playbook demonstrating the basic structure and compilation workflow. This playbook creates a hello world script, executes it, and optionally cleans up.

## Prerequisites

Before starting, verify:

**Required Software:**
```bash
# Check Bash version
bash --version | head -1
# Expected: GNU bash, version 4.0 or later

# Check write permissions
touch test.txt && rm test.txt && echo "✓ Write permission OK"
```

**Required Environment:**
- Operating System: Any (Linux/macOS/Windows with Bash)
- Required Permissions: Regular user (no sudo required)
- No external dependencies

## Instructions

### Step 1: Create Hello World Script

**Objective:** Create a simple bash script that prints "Hello World from CAPS!"

**Commands:**
```bash
# Create hello.sh script with greeting message
cat > hello.sh <<'EOF'
#!/bin/bash
echo "=========================================="
echo "Hello World from CAPS Playbook!"
echo "=========================================="
echo ""
echo "Current timestamp: $(date)"
echo "Current directory: $(pwd)"
echo "Current user: $(whoami)"
echo ""
echo "This script was generated by a CAPS playbook"
echo "and compiled to Claude Skills / Goose Recipes"
echo "=========================================="
EOF

# Make the script executable
chmod +x hello.sh
```

**Expected Output:**
```
(No output - files created silently)
```

**Success Criteria:**
- [ ] hello.sh file exists
- [ ] hello.sh has executable permissions

---

### Step 2: Verify Script Creation

**Objective:** Verify that the script was created successfully with correct content

**Commands:**
```bash
# Check if file exists
ls -la hello.sh

# Display script content
echo "Script content:"
cat hello.sh
```

**Expected Output:**
```
-rwxr-xr-x 1 user group 245 Dec 19 18:00 hello.sh
Script content:
#!/bin/bash
echo "=========================================="
Hello World from CAPS Playbook!
...
```

**Success Criteria:**
- [ ] File exists with executable permissions (-rwx)
- [ ] File contains expected content

---

### Step 3: Execute Hello World Script

**Objective:** Run the hello world script and verify output

**Commands:**
```bash
# Execute the script
./hello.sh
```

**Expected Output:**
```
==========================================
Hello World from CAPS Playbook!
==========================================

Current timestamp: Thu Dec 19 18:00:00 UTC 2025
Current directory: /path/to/current/dir
Current user: username

This script was generated by a CAPS playbook
and compiled to Claude Skills / Goose Recipes
==========================================
```

**Success Criteria:**
- [ ] Script executes without errors
- [ ] Output displays greeting message
- [ ] Timestamp and environment info shown

---

### Step 4: Cleanup (Optional)

**Objective:** Remove the generated script file

**Commands:**
```bash
# Remove the hello.sh script
rm hello.sh

# Verify removal
ls hello.sh 2>&1 || echo "Script successfully removed"
```

**Expected Output:**
```
ls: cannot access 'hello.sh': No such file or directory
Script successfully removed
```

**Success Criteria:**
- [ ] Script file no longer exists

## Validation

Success criteria (all must pass):

- [ ] **Script Created:** `test -f hello.sh && echo "PASS" || echo "FAIL"`
- [ ] **Script Executable:** `test -x hello.sh && echo "PASS" || echo "FAIL"`

**Quick Validation Script:**
```bash
# Run all checks
test -f hello.sh && \

  echo "❌ Some validation checks failed"
```

## Troubleshooting

**Problem:** Permission denied when executing
**Symptoms:** `bash: ./hello.sh: Permission denied`
**Root Cause:** Script was created but not made executable
**Check:**
```bash
# Check file permissions
ls -la hello.sh
# Should show -rwx (executable bit set)
```
**Fix:**
```bash
# Make the script executable
chmod +x hello.sh

# Verify permissions
ls -la hello.sh
```

---

**Problem:** Script not found
**Symptoms:** `bash: ./hello.sh: No such file or directory`
**Root Cause:** Script creation failed or wrong directory
**Check:**
```bash
# Check current directory
pwd

# List files to verify script exists
ls -la | grep hello
```
**Fix:**
```bash
# Navigate to correct directory
cd /path/to/expected/directory

# Or re-create the script using Step 1 commands
cat > hello.sh <<'EOF'
#!/bin/bash
echo "Hello World from CAPS Playbook!"
EOF
chmod +x hello.sh
```

---

**Problem:** Command not found
**Symptoms:** `bash: cat: command not found` or `bash: chmod: command not found`
**Root Cause:** Basic Unix commands not available in PATH
**Check:**
```bash
# Check if commands exist
which cat
which chmod
which echo

# Check PATH variable
echo $PATH
```
**Fix:**
```bash
# Use full paths if needed
/bin/cat > hello.sh <<'EOF'
#!/bin/bash
echo "Hello World"
EOF
/bin/chmod +x hello.sh

# Or add standard directories to PATH
export PATH=$PATH:/bin:/usr/bin
```
